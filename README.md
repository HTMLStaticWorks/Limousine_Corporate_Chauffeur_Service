# Premium Chauffeur Website — RTL Edition

A responsive limousine/corporate chauffeur front-end built from the transportation/logistics structure discussed in the project.

## Included
- Home + Home2
- Services, Fleet, Corporate, Pricing, About, Contact
- Client Login and Dashboard
- 100% RTL document/layout direction
- Light/Dark theme switcher as an icon-only header control; preference persists in localStorage
- Header primary action changed from Book Now to Dashboard
- Mobile menu and persistent mobile booking CTA
- Working demo booking/contact forms, fleet interactions, toasts, scroll reveal and back-to-top
- Premium transportation visual language with route/status UI

This is a front-end demonstration. Real authentication, booking persistence, GPS tracking, payments and billing require backend/API integration.
